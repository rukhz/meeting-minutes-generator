
# Smart Meeting Minutes Generator

A smart system that automatically generates meeting minutes from online meetings using speech-to-text processing and summarization.

## Features
- Speech-to-text conversion
- Meeting transcript generation
- Automatic summarization
- Action item extraction
- User-friendly Flutter interface

## Technologies Used
- Flutter
- Python
- Flask

## Project Objective
The goal of this project is to reduce manual note-taking effort during meetings by automatically generating organized meeting minutes.
