# Setup – Flutter App

## 1. Flutter app

```bash
flutter pub get
flutter run -d <device>
```

## 2. Backend (Flask, on PC)

From the **project root**:

```bash
cd minutes_generator_jitsi_meet
python app.py
```

Or run **START_FOR_CLIENT.bat** (root folder) to start Flask only.

## 3. App configuration

- **Flask Server URL:** `http://YOUR_PC_IP:5000` (e.g. `http://192.168.1.5:5000`)
- Use **Auto** to find the PC on the network, or **Test** to check the URL
- Phone and PC must be on the **same Wi‑Fi**

Full flow and troubleshooting: **[FUNCTIONALITY.md](../FUNCTIONALITY.md)** in the project root.
