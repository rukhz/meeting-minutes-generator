# Smart Meeting Minutes – Flutter App

Flutter app that creates Jitsi Meet meetings and shows meeting minutes. The **backend** is the Flask app in `../minutes_generator_jitsi_meet/` (Python, port 5000); it runs the Jitsi bot, recording, and minutes generation.

## Setup

```bash
flutter pub get
flutter run -d <device>
```

## Usage

1. **Start the Flask backend** on your PC: `cd minutes_generator_jitsi_meet && python app.py`
2. In the app, set **Flask Server URL** to `http://YOUR_PC_IP:5000` (or use **Auto** / **Test**)
3. Tap **Start Meeting** → join Jitsi and speak
4. Tap **Stop Meeting** (or leave Jitsi) → minutes are generated and shown

See the root **[FUNCTIONALITY.md](../FUNCTIONALITY.md)** for full flow and troubleshooting.

## Project structure (relevant)

- `lib/screens/meeting_home_page.dart` – Meeting UI (Start/Stop, Flask URL, minutes)
- `lib/services/flask_bot_service.dart` – Calls Flask: join, leave, meeting-minutes
- `lib/services/recording_service.dart` – Used for Auto-detect (Flask URL on port 5000)
- `lib/services/jitsi_service.dart` – Jitsi Meet integration
